## 🚀 How to Run the Programs

Ensure Python is installed on your computer.

1. Open your terminal in this repository.
2. Run any Python script using:
   ```powershell
   python <path-to-script>.py
   ```
   *Example:*
   ```powershell
   python projects/01-cipher/main.py
   ```

## 🔄 Daily Git Workflow Cheat Sheet

Whenever you finish a lesson, solve an exercise, or update notes:

```powershell
# 1. Check which files were modified
git status

# 2. Stage the changes
git add .

# 3. Commit with a clear, descriptive message
git commit -m "Add notes on string methods"

# 4. Push to GitHub
git push
```
