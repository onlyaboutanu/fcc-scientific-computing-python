# 🔐 Project 01: Caesar Cipher

In this project from freeCodeCamp, you learn the fundamentals of string manipulation, loops, and functions by building a Caesar Cipher encryption and decryption program.

## Concepts Learned
- String indexing and slicing
- The `.find()` and `.index()` methods
- `for` loops and iteration over strings
- Modulo arithmetic (`%`) for wrapping around the alphabet
- Defining and calling functions with parameters and return values

## File Structure
- `main.py` — Your cipher implementation.
- `README.md` — Project notes and summary.

## How to Run
```powershell
python projects/01-cipher/main.py
```
