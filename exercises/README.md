# 🏋️ Practice Exercises

Use this folder to experiment with small coding exercises, drills, and playground scripts.

## How to organize your exercises
- Name files descriptively based on the topic:
  - `01_string_indexing.py`
  - `02_loops_practice.py`
  - `03_function_drills.py`
- Run your scripts from terminal:
  ```powershell
  python exercises/01_string_indexing.py
  ```

> 💡 **Tip:** Add comments explaining what tricky parts do or what error you encountered and resolved!
